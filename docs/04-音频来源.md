# 04 · 音频来源与映射

> 仅记录本地构建所用的 OGG 来源；公开分发前应重新评估授权/署名。

## 来源

- 16 首 TH01 gamerip：KHInsider 专辑页
  `https://downloads.khinsider.com/game-soundtracks/album/touhou-reiiden-highly-responsive-to-prayers.-pc-9801`
- 曲目/关卡对应关系参考：
  - VGMRips 曲目表：`https://vgmrips.net/packs/pack/touhou-reiiden-highly-responsive-to-prayers-nec-pc-9801`
  - THBWiki 音乐列表：`https://cache-server.thwiki.cc/官方音乐列表`

处理流程：

1. 从 KHInsider 下载 MP3。
2. `mpg123` 解码为 44.1 kHz / 16-bit WAV。
3. `oggenc2`（libvorbis 1.3.7，`-q 4`）编码为 OGG。
4. 放入 `android/app/src/main/assets/th01/bgm/01.ogg … 16.ogg`。

## 运行时映射

`port/audio_ogg.cpp` 的 `track_for()`：

- `st0`/`st6` → 02
- `st1` → 04
- `st2` → 05
- `st3` → 07
- `st4` → 08
- `st5` → 10
- `positive` → 03
- `legend` → 06
- `kami` → 09
- `kami2` → 16
- `tensi` → 11
- `syugen` → 12
- `alice` → 13
- `iris` → 14
- `reimu`/`init` → 01
- `zipangu` → 15

音频以 `stb_vorbis` 流式解码，避免把整首 7 分钟曲目常驻内存。
