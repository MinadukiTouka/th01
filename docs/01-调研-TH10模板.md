### 3.2 Gradle

`app/build.gradle.kts` 关键点：

```kotlin
android {
    namespace = "com.zun.th10"
    compileSdk = 36
    ndkVersion = "27.1.12297006"

    defaultConfig {
        applicationId = "com.zun.th10"
        minSdk = 26
        targetSdk = 36
        versionCode = ...
        versionName = ...
        ndk { abiFilters += listOf("arm64-v8a") }
        externalNativeBuild { ndkBuild { } }
    }
    externalNativeBuild {
        ndkBuild { path = file("src/main/jni/Android.mk") }
    }
    signingConfigs { create("th10") { ... } }
    buildTypes { release { ... } debug { ... } }
    sourceSets {
        getByName("main") {
            java.srcDir(File(thirdPartyDir, "SDL2/android-project/app/src/main/java"))
        }
    }
    packaging { jniLibs { useLegacyPackaging = false } }
    androidResources { noCompress += listOf("dat", "ttc") }
}
```

- `settings.gradle.kts`：`google()` + `mavenCentral()` + `gradlePluginPortal()`。
- 根 `build.gradle.kts`：`com.android.application` 9.4.1。
- `gradle.properties`：`org.gradle.jvmargs=-Xmx2g`、`android.useAndroidX=true`、`android.overridePathCheck=true`。
- `versionCode` 由 `versionName` 推出：`major*10000 + minor*100 + patch`。

### 3.3 Manifest

- `MANAGE_EXTERNAL_STORAGE` + `READ_EXTERNAL_STORAGE (maxSdk 32)`。
- `uses-feature glEsVersion=0x00030000 required=true`。
- `application`：`extractNativeLibs=false`、`allowBackup=true`、`hasFragileUserData=true`。

## 4. 渲染 / 音频 / 输入 / 打包

### 4.1 渲染

- TH10 上游 `portable/sdl/Renderer.cpp` 已经是 GLES3；Android 只改了窗口创建（`SDL_CreateWindow(..., 0,0,0,0, OPENGL|FULLSCREEN)`）。
- 4:3 居中 + 黑边 + `picture{}` 矩形都在 Renderer 里；触控坐标反算也走它。
- TH01 只需要 2D：可以更简单——`SDL_CreateTexture(640×400, RGBA8888, STREAMING)` + 每帧 `SDL_UpdateTexture` + `SDL_RenderCopy`。SDL2 Android 后端会用 GLES。

### 4.2 音频

- TH10 用 SDL2 的 queued audio（`SDL_OpenAudioDevice` + `SDL_QueueAudio`）；Android 后端落到 AAudio/OpenSL。
- 音效/音乐在 host 层混音后推队列。
- TH01 阶段 3 可以复用同一套：OGG（stb_vorbis）→ PCM → `SDL_QueueAudio`。

### 4.3 触屏

- TH10 游戏内的触控走 SDL finger event；Esc/✕ 是 Java 覆盖层。
- 惯用手：`SharedPreferences("port", "left_handed")` → `nativeSetHandedness(0|1)` → 原生只改 `bomb_side`。
- TH08 的做法更完整：`touch.rs` 的 `Handed` / `TouchConfig.handed`，`place()` 镜像、`bomb_zone()` 选边、安全区、gesture exclusion。
- TH01 应取两者：
  - 按键式布局（不是 TH08 的 analog 拖动）；
  - 惯用手镜像 + 安全区；
  - Java 覆盖层按钮（避免 SurfaceView 吃掉触摸/按键）。

### 4.4 数据目录

TH10 的三档搜索：

```
/storage/emulated/0/Download/th10                 需要 MANAGE_EXTERNAL_STORAGE
/sdcard/Android/data/com.zun.th10/files/th10      adb push，无需权限
/data/data/com.zun.th10/files/th10                私有
```

存档单独写 `<external-files>/th10-save`，数据目录只读。
TH01 沿用三档，但要把 CP932 文件名规范化（见 PLAN §5.5）。

### 4.5 打包

- `scripts/build-apk.ps1`：`Invoke-Gradle` + `Publish-Apk` + `Test-Apk`。
- `Test-Apk` 做：`apksigner verify`、`aapt2 dump badging`、解压 APK 检查 `assets/` 没有游戏数据、检查 `lib/arm64-v8a/libmain.so` 和 `libSDL2.so`。
- 公开包 vs `-full` 包：`-Pth10.bundleFont` / `-Pth10.bundleGameData`。
- `secrets/`、`dist/`、`game-data/`、`third_party/` 都在 `.gitignore`。

## 6. 构建环境注意

1. **中文路径**：Gradle/CMake 的参数不要塞中文绝对路径；先 `Set-Location` 到 `C:\th01ws`，再用相对路径。
2. **exFAT**：中间产物放 `C:\th08-toolchain\build-target-th01`，不要留在 E:。
3. **Ninja**：CMake 必须显式 `-G Ninja` + `CMAKE_MAKE_PROGRAM`；否则会报 “unable to find a build program”。
4. **CMake 0xC0000409**：本次未复现；若 Gradle 集成再次出现，记录完整命令/日志，再回退 ndk-build。
5. **PowerShell 5.1**：`-Pfoo.bar=1` 会被拆成两个参数；用数组 splat（TH10 `Invoke-Gradle` 已处理）。
